🧹 Data Cleaning & Transformation | Power BI

1. Overview

Data cleaning and transformation were performed using Power Query Editor in Microsoft Power BI to prepare the raw Retail Store Sales dataset for analysis and dashboard development.

The objective was to organize the raw data, establish appropriate data types, modify selected values, create a custom column, remove unnecessary columns and prepare the dataset for visualization.

2. Data Preparation Workflow

The following eight transformation steps were applied in Power Query Editor.

Step 1: Source

Imported the original Retail Store Sales CSV dataset into Power BI.

Step 2: Promoted Headers

Promoted the first row of the dataset as column headers to ensure that each field had an appropriate column name.

Step 3: Changed Type

Assigned appropriate data types to the dataset columns to support accurate data processing and calculations.

Step 4: Replaced Value

Used the Replace Values transformation to replace selected values within the dataset.

Step 5: Added Custom

Created a custom column using Power Query's Custom Column feature to introduce an additional calculated or derived field.

Step 6: Removed Columns

Removed unnecessary columns that were not required for the intended analysis.

Step 7: Renamed Columns

Renamed selected columns to improve readability and make the dataset easier to understand.

Step 8: Changed Type1

Applied additional data type corrections to ensure that the transformed columns had the appropriate data formats.

3. Data Transformation Summary

The Power Query workflow involved:

Importing the raw CSV dataset.

Promoting headers.

Correcting column data types.

Replacing selected values.

Creating a custom column.

Removing unnecessary columns.

Renaming selected columns.

Applying final data type corrections.

4. Final Outcome

After completing these transformations, the dataset was prepared for further analysis and Power BI dashboard development.

The transformed data was used to build visualizations covering:

Overall Sales Performance

Category-Wise Sales

Yearly Sales Trends

Payment Method Analysis

Product Quantity Analysis

Location-Wise Sales Performance

The Power Query transformation process helped organize the raw retail sales dataset and prepare it for business analysis.

These preparation steps provided the foundation for developing an interactive Sales Performance Analytics Dashboard and extracting meaningful business insights.
